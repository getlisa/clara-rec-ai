## Clara-Assistant

An Android companion app for Ray-Ban Meta smart glasses. See a live view from the glasses camera, record it to video with audio, and get AI analysis of what you're looking at.

Built on the [Meta Wearables Device Access Toolkit](https://wearables.developer.meta.com/docs/getting-started-toolkit) (DAT).

> [!NOTE]
> **Developer Mode** must be enabled in the **Meta AI** app before the glasses will accept a connection. See [Detailed setup](#detailed-setup) below.

> [!IMPORTANT]
> This project is built from source — there is no APK release and it is not on the Play Store. The Meta SDK it depends on is distributed through GitHub Packages and requires a GitHub token to fetch. See [Building](#building).

## Features

### 🎥 Live view
Stream the glasses camera to your phone in real time. Video quality (low / medium / high) is configurable in Settings.

### 🔴 Recording
Record the live view to an MP4 on your phone. Recordings are saved to shared storage at `Movies/Clara-Assistant/`, so they appear in your Gallery and Files app and survive uninstalling the app. Browse, play back, and delete them from the **Clips** tab.

Recording captures video from the glasses and audio from the **phone microphone**, muxed into a single file as H.264 video + AAC audio.

> [!NOTE]
> The glasses' own microphone is not currently used for recording. The DAT SDK exposes no audio stream — glasses audio is only reachable through the phone's Bluetooth Hands-Free Profile (HFP), which is a separate subsystem the app would have to bridge and sync itself. Denying the microphone permission is not fatal: recording falls back to video-only.

### 📸 Picture analysis
Take a picture through the glasses and get an on-screen description of what the camera sees, generated by OpenAI.

### 🕘 History
Review transcripts of past conversation sessions.

### ⚙️ Settings
Connect and disconnect glasses, choose video quality, set your OpenAI API key, and customize the AI system instructions.

## Requirements

- Ray-Ban Meta smart glasses, powered on
- Android **12 or newer** (the app targets API 31+)
- The **Meta AI** app installed, with **Developer Mode** enabled
- Glasses paired and connected in the Meta AI app
- Bluetooth enabled
- An [OpenAI API key](https://help.openai.com/en/articles/4936850-where-do-i-find-my-openai-api-key) for the AI features
- A GitHub token with `read:packages` scope, to fetch the Meta SDK (see below)

## Building

### Prerequisites
- Android Studio (latest stable)
- Android SDK + Platform Tools
- JDK 17 — newer JDKs will not work with this project's Gradle version

### Configure `android/local.properties`

The Meta SDK (`meta-wearables-dat-android`) is served from GitHub Packages, which requires authentication even for public packages. Create a [personal access token](https://github.com/settings/tokens) (classic) with the `read:packages` scope, then add it to `android/local.properties` — this file is gitignored and must never be committed:

```properties
sdk.dir=/path/to/Android/sdk
github_token=YOUR_GITHUB_TOKEN

# Optional: needed only for the AI features
OPENAI_API_KEY=YOUR_OPENAI_KEY
OPENAI_MODEL=gpt-4o
```

The OpenAI key can also be set at runtime in the app's Settings screen.

### Build and install

```bash
cd android
export JAVA_HOME=/path/to/jdk-17
./gradlew :app:installDebug
```

Or build the APK and install it yourself, which is faster over a slow adb connection:

```bash
./gradlew :app:assembleDebug
adb install -r app/build/outputs/apk/debug/app-debug.apk
```

To open in Android Studio, choose **Open** and select the `android/` folder (not the repository root).

### Tests

Instrumented tests covering the video encoder require a connected device or emulator:

```bash
./gradlew :app:connectedDebugAndroidTest
```

## Detailed setup

> [!WARNING]
> **Developer Mode is required.** Your Meta glasses will not connect to third-party apps until it is enabled in the Meta AI app.
>
> **How to enable:**
> 1. Open the **Meta AI** app on your phone
> 2. Go to **Settings** → **App Info** (this is the app's settings, not the glasses settings)
> 3. Tap the **App version** number **five times quickly** — this reveals the Developer Mode toggle
> 4. Enable the **Developer Mode** toggle
> 5. Tap **Enable** to confirm
>
> <img src="docs/images/meta-view-develop-mode.png" alt="Meta AI Developer Mode" width="50%" />
>
> See the [Meta Wearables Setup Guide](https://wearables.developer.meta.com/docs/getting-started-toolkit) for details.

Once Developer Mode is on:

1. Launch Clara-Assistant and allow the nearby devices permission so it can reach the glasses.
2. Open **Settings** and tap **Connect my glasses**.
3. On the Meta device prompt, enable the toggle and tap **Connect**.
4. Paste your OpenAI API key into Settings and save it.
5. Tap **Check Connection** — it should report **Connection OK**.
6. Grant the microphone permission the first time you record, if you want audio.

> [!TIP]
> If streaming pauses or Bluetooth drops, disable battery restrictions for the app:
> `Settings → Battery → Clara-Assistant → Battery Saver → No restrictions`

## Privacy

- Images and audio are sent only to OpenAI, using your own account and API key, and only for AI processing.
- Your OpenAI API key is stored locally on your phone and is never logged.
- Recordings are stored on your device and are not uploaded anywhere.
- API communication uses HTTPS.
